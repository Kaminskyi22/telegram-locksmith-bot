# Telegram Locksmith Bot

Простий Telegram-бот для прийому повідомлень та локацій від користувачів з автоматичною пересилкою адміністратору.

## Функціонал

- Прийом повідомлень від користувачів
- Прийом геолокації
- Автоматична пересилка всіх повідомлень адміністратору
- Підтвердження отримання повідомлень користувачам

## Налаштування та розгортання

### 1. Налаштування на GitHub

1. Створіть новий репозиторій на GitHub
2. Клонуйте репозиторій на локальний комп'ютер
3. Скопіюйте всі файли проєкту в папку репозиторію
4. Зробіть коміт та відправте зміни на GitHub:
   ```bash
   git add .
   git commit -m "Initial commit"
   git push origin main
   ```

### 2. Налаштування на Render.com

1. Створіть обліковий запис на [Render.com](https://render.com)
2. Натисніть "New +" та виберіть "Web Service"
3. Підключіть ваш GitHub репозиторій
4. Налаштуйте сервіс:
   - **Name**: Введіть назву вашого сервісу
   - **Environment**: Python
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `bash start.sh`
5. Додайте змінні середовища:
   - `BOT_TOKEN`: Токен вашого Telegram-бота (отримайте у @BotFather)
   - `ADMIN_CHAT_ID`: ID чату адміністратора (можна отримати через @userinfobot)
6. Натисніть "Create Web Service"

## Структура проєкту

- `telegram_locksmith_bot.py` - основний код бота
- `requirements.txt` - залежності проєкту
- `start.sh` - скрипт для запуску бота
- `README.md` - документація

## Змінні середовища

- `BOT_TOKEN` - токен вашого Telegram-бота
- `ADMIN_CHAT_ID` - ID чату адміністратора

## Примітки

- Бот працює 24/7 на Render.com
- Всі повідомлення та локації автоматично пересилаються адміністратору
- Користувачі отримують підтвердження про отримання їх повідомлень
